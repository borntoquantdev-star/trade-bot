# Dashboard — ดูบอททำงานแบบ realtime

หน้าเว็บที่แสดงว่าบอทกำลังทำอะไรอยู่: ข้อมูลตลาดที่มันเห็น สัญญาณที่กลยุทธ์ออก
ด่านความเสี่ยงอนุมัติหรือปฏิเสธ และออเดอร์ที่ส่งไป — เป็นสายโซ่ node ต่อกัน
อัปเดตเองทันทีที่บอทตัดสินใจรอบใหม่

```bash
hyperbot --dry-run --paper-walk --iterations 60     # หน้าต่างที่ 1: บอท
node dashboard/server.js --open                     # หน้าต่างที่ 2: dashboard
```

แล้วเปิด http://127.0.0.1:4317

## มันทำงานยังไง

```
hyperbot  ──เขียน──>  logs/audit.jsonl   1 บรรทัด = 1 การตัดสินใจ
                      logs/state.json    ทุนต้นวัน จุดสูงสุด สถานะ halt
                            │
                            │  server.js เฝ้าไฟล์ (poll 500ms) อ่านเฉพาะส่วนที่เพิ่ม
                            ▼
                      SSE /api/stream
                            │
                            ▼
                      หน้าเว็บวาด node graph + กราฟราคา + log
```

**dashboard ไม่แตะบอทเลย** มันอ่านไฟล์ฝ่ายเดียว ไม่ได้ต่อตลาด ไม่มีทางส่งคำสั่ง
ปิดหน้าเว็บหรือฆ่าเซิร์ฟเวอร์ไม่กระทบบอทที่กำลังรัน และถ้า dashboard พัง บอทก็ไม่รู้ด้วยซ้ำ
นี่คือเหตุผลที่แยกเป็นคนละโปรเซส ไม่ยัดเว็บเซิร์ฟเวอร์เข้าไปในลูปเทรด

## ห้าขั้นที่เห็นบนหน้าจอ

| ขั้น | เป็น ready เมื่อ | เป็น blocked / error เมื่อ |
|---|---|---|
| ข้อมูลตลาด | อ่านราคาและทุนได้ | `broker read failed` |
| กลยุทธ์ | ออกสัญญาณในรอบนี้ | กลยุทธ์ throw |
| ด่านความเสี่ยง | อนุมัติเป็น `SizedOrder` | ปฏิเสธ (โชว์ reject code เป็นภาษาไทย) หรือบอท halt |
| ส่งคำสั่ง | ตลาดรับออเดอร์แล้ว | broker ปฏิเสธ · เป็นสีฟ้าประถ้าเป็น paper |
| ไม้ที่ถืออยู่ | มี position เปิดอยู่ | — |

สีขอบการ์ด: เทา = รอ · เหลือง = กำลังทำ · เขียว = พร้อม · แดง = ถูกปฏิเสธ · ฟ้าประ = จำลอง

## ตัวเลือก

```bash
node dashboard/server.js --help
  --port <n>     ค่าตั้งต้น 4317
  --host <ip>    ค่าตั้งต้น 127.0.0.1 (เปิดเฉพาะในเครื่องนี้)
  --logs <dir>   โฟลเดอร์ log ของบอท (ค่าตั้งต้น ../logs)
  --poll <ms>    ความถี่ตรวจไฟล์ (ค่าตั้งต้น 500)
  --open         เปิดเบราว์เซอร์ให้
```

ถ้าบอทเขียน log ไว้ที่อื่น (`--audit-file` / `--state-file`) ให้ชี้ `--logs` ไปโฟลเดอร์นั้น

`--host 0.0.0.0` ทำได้แต่**ไม่ควร**: หน้านี้เปิดสถานะพอร์ตและยอดเงินของคุณ และไม่มีการล็อกอิน

## API

| route | ได้อะไร |
|---|---|
| `GET /api/stream` | SSE · ส่ง `snapshot` ทุกครั้งที่ไฟล์เปลี่ยน |
| `GET /api/snapshot` | JSON ภาพปัจจุบัน (ใช้เทสหรือเอาไปต่อเครื่องมืออื่น) |

รูปร่างของ snapshot มาจาก `lib/pipeline.js` → `derive()` ซึ่งเป็น pure function
ไฟล์เดียวกันถูกใช้ทั้งฝั่งเซิร์ฟเวอร์และฝั่งเบราว์เซอร์ จึงไม่มีทางคิดไม่ตรงกัน

## เทส

```bash
cd dashboard && npm test        # 32 เทส ไม่ต้องต่อเน็ต ไม่ต้องมีบอทรันอยู่
```

ครอบ: การอ่านไฟล์แบบต่อท้าย (บรรทัดที่ยังเขียนไม่จบ, ไฟล์ถูกเริ่มใหม่, JSON เสีย),
การแปลงเป็น node graph ทุกสถานะ, คำแปล reject code ทั้ง 13 ตัว,
และเทสจริงที่เปิดเซิร์ฟเวอร์ ต่อ SSE แล้วเขียนบรรทัดใหม่ลงไฟล์เพื่อดูว่ามันถึงหน้าเว็บ

## ข้อจำกัด

- **แสดงอดีต ไม่ใช่อนาคต** ทุกอย่างบนหน้านี้คือสิ่งที่บอทบันทึกไว้แล้ว
- **ช้ากว่าบอทได้ถึง 500ms** ตามรอบ poll (ปรับด้วย `--poll` ได้แต่ไม่ช่วยอะไรมาก)
- **เก็บแค่ 2,000 บรรทัดล่าสุด** ในหน่วยความจำ ของเก่ากว่านั้นยังอยู่ในไฟล์แต่ไม่ขึ้นจอ
- **กราฟคือราคาที่บอทเห็นตอนตัดสินใจ** ไม่ใช่กราฟแท่งเทียนของตลาด
- **ไม่มีการล็อกอิน** เพราะผูกกับ 127.0.0.1 เท่านั้น
